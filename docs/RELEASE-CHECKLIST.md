# قائمة فحص الإصدار — زهرة 3.1

> هذه ليست قائمة «تم»؛ هي قائمة تحقق بحالة كل بند. البنود التي لم تُنفَّذ مكتوبة
> صراحةً. لا يُعتبر الإصدار جاهزًا للنشر حتى تُغلق البنود الحرجة بقرار مالك
> وتشغيل فعلي، لا بتعديل النص.

## الحالة الإجمالية

**غير جاهز للنشر.** السبب: لا APK موقّع، لا قياس، لا اختبار جهاز، لا مراجعة
أمنية/قانونية/بشرية، ولا قرار قناة توزيع.

## قواعد

- لا تُغيّر ✅ إلى «منجز» لأن الملف موجود؛ الدليل هو الأمر/المخرج.
- لا تحذف بندًا غير منفّذ؛ انقله إلى [POST-RELEASE](POST-RELEASE.md) بمالك وتاريخ.
- لا تنشر رقمًا لا يحمل أمرًا/تاريخًا/commit/هاش.
- أي تغيير في المحتوى/الأذونات/التشفير يستلزم إعادة الفحص كاملًا.
