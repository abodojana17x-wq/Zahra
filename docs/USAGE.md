# دليل الاستخدام — زهرة 3.1

> **لا يوجد APK منشور حاليًا.** يمكنك بناء التطبيق من المصدر إذا كانت لديك بيئة
> Android كاملة. إذا لم تكن مطورًا، فأنت تحتاج إلى انتظار قرار المالك بشأن قناة
> التوزيع؛ لا تعتمد على روابط غير رسمية.

## البداية السريعة

1. ثبّت **JDK 21** و**Android SDK** (Platform 36 + Build Tools).
2. من جذر المستودع، ابنِ نسخة debug:
   ```bash
   ./gradlew :app:assembleDebug --no-daemon
   ```
3. ستجد الملف في `app/build/outputs/apk/debug/app-debug.apk` (المسار القياسي
   المتوقع؛ لم يُتحقق منه في هذه البيئة لأن البناء لم يُشغَّل).
4. ثبّته على جهاز/محاكي:
   ```bash
   adb install -r app/build/outputs/apk/debug/app-debug.apk
   ```
5. افتح التطبيق واكتب سؤالك في الشاشة الرئيسية. لا يُطلب حساب ولا اتصال بالإنترنت.

> **تحذير:** نسخة debug ليست نسخة إصدار. قد تحتوي على مفاتيح debug وتشخيصات إضافية،
> ولم تُختبر على أي جهاز هنا. لا توزّعها بوصفها إصدارًا نهائيًا.

## ما يمكنك فعله

- **حساب ووحدات:** تعبيرات حسابية بالأرقام العربية/الإنجليزية، تحويلات وحدات،
  وحل مسائل كلامية محددة.
- **وقت وتاريخ:** التاريخ الميلادي والهجري (أم القرى على Android المدعوم)،
  وأدوات الوقت المحلية.
- **معرفة محلية:** استرجاع من 181 وحدة معرفة في 11 حزمة، مع امتناع صريح عند غياب
  الدليل بدل اختراع إجابة.
- **محادثة قصيرة:** إحالات مثل «وإيه عاصمتها؟» ضمن حدود الحالة القصيرة، مع سؤال
  توضيحي عند الغموض.
- **مهام وملاحظات ومواعيد:** أدوات محلية. الملاحظات مشفرة؛ المهام والمواعيد غير
  مشفرة بطبقة التطبيق (انظر [الخصوصية](PRIVACY.md)).
- **تشخيص داخل التطبيق:** من الإعدادات ← «تشخيص» لتشغيل فحوصات حساب/وحدات/أصول/
  ذاكرة/شبكة على الجهاز الآن.
- **حالة الإصدار والقيود:** من الإعدادات ← «الاستخدام والحدود».

## البناء من المصدر

### المتطلبات

| المتطلب | الإصدار/الملاحظة |
|---|---|
| JDK | 21 (مطلوب في CI) — المشروع يستهدف Java 11 في `compileOptions` |
| Gradle | wrapper موجود (`gradlew`)؛ لا تحتاج تثبيتًا منفصلًا |
| Android SDK | Platform 36 · Build Tools متوافقة |
| الشبكة | لتنزيل التبعيات أثناء البناء فقط؛ التطبيق نفسه بلا إذن شبكة |

### أوامر

```bash
# اختبارات الوحدة (لم تُشغَّل هنا)
./gradlew :app:testDebugUnitTest --no-daemon

# هارنس القياس 223 حالة × 8 (لم يُشغَّل هنا)
./gradlew :app:testDebugUnitTest --tests 'com.example.eval.EvalReportTest' --no-daemon

# APK debug
./gradlew :app:assembleDebug --no-daemon

# فحوصات Python التي لا تحتاج Android SDK
python3 scripts/validate_eval.py --phase 06
python3 tools/test_phase06.py
```

بناء **release** يحتاج متغيرات `KEYSTORE_PATH` و`STORE_PASSWORD` و`KEY_PASSWORD`
ووجود مفتاح `upload`. لم يُختبر هذا المسار هنا. راجع
[التوزيع](DISTRIBUTION.md) و[الأمان](SECURITY.md) قبل أي توقيع.

## الأذونات

| الإذن | لماذا | متى يُطلب |
|---|---|---|
| `POST_NOTIFICATIONS` | إشعارات محلية للمواعيد/المنبهات | على Android 13+ عند إعداد إشعار |
| `RECORD_AUDIO` | الإدخال الصوتي إن استُخدم | عند بدء التسجيل |
| `VIBRATE` | تنبيه اهتزاز محلي | لا يُطلب عادة |
| `SCHEDULE_EXACT_ALARM` | منبهات دقيقة | قد يوجهك النظام لتمكينه |
| `RECEIVE_BOOT_COMPLETED` | إعادة جدولة المنبهات بعد إعادة التشغيل | لا يظهر كطلب عادي |

**لا يوجد إذن `INTERNET` ولا `ACCESS_NETWORK_STATE`.** لذلك لا يستطيع التطبيق
فتح اتصال شبكي بنفسه، ولا تعمل أدوات الطقس/ويكيبيديا الاختيارية حتى يقرر المالك
تغيير ذلك (D1). هذا قيد تصميم لا خطأ.

## الخصوصية والبيانات في لمحة

- لا حساب سحابي ولا مزامنة ولا تحليلات خادمية.
- المحادثات والأرشيف والذاكرة والملاحظات مشفرة محليًا (AES-GCM/AndroidKeyStore).
- المهام والمواعيد ومفكرة المزاج وتفضيلات الشخصية محفوظة في SharedPreferences
  خاصة بالتطبيق **دون تشفير إضافي**.
- زر مسح الذاكرة يمسح حقائق الذاكرة والمواضيع الحالية، ولا يمسح الأرشيف أو الملاحظات
  أو المهام؛ راجع نص التأكيد داخل التطبيق.
- التفاصيل الكاملة والنسخ الاحتياطي والنقل بين الأجهزة: [الخصوصية](PRIVACY.md).

## ما لا يفعله التطبيق

- لا يفتوى ولا يشخّص ولا يوصف دواءً؛ المحتوى الديني ملخصات تحيل إلى مراجع،
  والمحتوى الصحي معلومات عامة.
- لا يضمن صحة كل إجابة أو تغطية كل لهجة أو سؤال.
- لا يشغّل كودًا من المستخدم (D3 معلّق).
- لا يستخدم embeddings (D2 معلّق) ولا نموذجًا توليديًا في النواة.
- لا يقرأ OCR من الصور خارج الصندوق: ملفات tessdata غير مشحونة، وML Kit يعتمد
  على خدمات جوجل. قد يُبقي التشخيص OCR معطّلًا بدل الانهيار.
- لا يعمل على iOS أو Web؛ هذا تطبيق Android (minSdk 24).
- لا يقدّم صوتًا عربيًا مضمونًا؛ يعتمد على محرك TTS في جهازك.

القائمة الكاملة: [القيود المعروفة](LIMITATIONS.md).

## التخزين والحذف

| البيانات | أين | التشفير |
|---|---|---|
| المحادثة الحالية والأرشيف | SharedPreferences | مشفر (AES-GCM) |
| ذاكرة المستخدم (حقائق) | SharedPreferences | مشفرة افتراضيًا؛ يمكن تعطيلها من الكود |
| الملاحظات | SharedPreferences | مشفرة |
| المهام | `zahra_tasks_prefs` | غير مشفرة بطبقة التطبيق |
| المواعيد | `zahra_schedules_prefs` | غير مشفرة بطبقة التطبيق |
| مزاج/مفكرة | `zahra_mood_journal` | غير مشفرة بطبقة التطبيق |
| تفضيلات الشخصية/الواجهة | `ZahraPersonalityPrefs` وغيرها | غير مشفرة |

لحذف كل شيء: امسح بيانات التطبيق من إعدادات Android أو أزل التطبيق. زر المسح
داخل التطبيق محدود النطاق ومقصود؛ لا يمحو الأرشيف والملاحظات والمهام.

## استكشاف الأخطاء

- **البناء يفشل عند `secrets`/Google services:** راجع إعداد `.env` وقاعدة
  `MissingGoogleServicesStrategy.WARN`؛ لم تُشغَّل هذه الخطوة هنا.
- **`assembleRelease` يفشل:** غالبًا مفتاح التوقيع/متغيرات البيئة مفقودة. لا تضع
  كلمة المرور في المستودع؛ استخدم متغيرات بيئة.
- **لا صوت:** تحقق من وجود محرك TTS عربي في الجهاز. التطبيق لا يضمنه.
- **OCR لا يعمل:** متوقع حاليًا (tessdata غير مشحونة). لا ترسل الصور لأي خدمة.
- **الطقس/المعرفة لا يعملان:** لا إذن شبكة؛ هذا هو الوضع الافتراضي.
- **التشخيص يُظهر فحصًا فاشلًا:** افتح التقاصيل؛ الفحص يعمل على جهازك ولا يُخفي
  الفشل. لا يعني فشل فحص أن كل التطبيق معطّل.
