# بطاقة نظام زهرة (System Card) — 3.1

> زهرة **ليست نموذجًا لغويًا**، ولا تُدرَّب ولا تحتوي أوزانًا. هي تطبيق Android
> يجمع قواعد وتطبيعًا عربيًا واسترجاعًا من حزم معرفة وأدوات حتمية. لذلك بطاقة
> النموذج التقليدية لا تنطبق حرفيًا؛ هذه بطاقة نظام تصف المكوّنات والاستخدام
> والقياس والقيود بأمانة.

## تفاصيل النظام

| البند | القيمة |
|---|---|
| الاسم | زهرة (Zahra) |
| النوع | مساعد محلي حتمي + استرجاع معرفة + أدوات |
| الإصدار | 3.1 (versionCode 2) |
| الحزمة | `com.aistudio.zahra.kpxq` |
| المنصة | Android، `minSdk 24`، `targetSdk 36` |
| اللغة | عربية (فصحى/مصرية) مع فهم إنجليزي/فرانكو جزئي |
| الشبكة | لا إذن INTERNET — Zero-Network افتراضيًا |
| النموذج التوليدي | **لا يوجد** في النواة (D9/D10 غير محسومين) |
| المحتوى | 181 وحدة في 11 حزمة (D31: مولّد آليًا بلا مراجعة بشرية) |
| الترخيص | شيفرة/محتوى بمزيج موثق جزئيًا — راجع [تدقيق التراخيص](../evidence/phase-05/license-audit.md) |

## الاستخدام المقصود

### استخدامات أساسية

- إجابة أسئلة معرفية قصيرة ووثّقها من الحزم المحلية، مع امتناع عند غياب الدليل.
- حساب وتعبيرات ووحدات وتحويلات.
- وقت/تاريخ هجري (أم القرى حيث يتوفر) وأدوات وقت محلية.
- تذكيرات وملاحظات ومواعيد محلية.
- حوار قصير متعدد الأدوار بسياق محدود وإحالات.
- تشخيص ذاتي على الجهاز (حساب/أصول/ذاكرة/شبكة).

### المستخدمون

- شخص يريد مساعدًا محليًا لا يرسل بياناته لخادم.
- مستخدم عربي على Android 7+ يقبل حدود الفهم والاسترجاع.
- مطور/باحث يريد بنية قابلة للتدقيق وإعادة الإنتاج.

### ظروف التشغيل

- جهاز Android حقيقي بلا شبكة.
- تخزين محلي متاح ومساحة كافية.
- TTS عربي اختياري (غير مضمون).
- لا حساب أو تسجيل دخول.

## خارج النطاق

- **لا فتوى شرعية** ولا حكم فقهي خلافي؛ ملخصات تحيل إلى مراجع وأهل العلم.
- **لا تشخيص/علاج طبي** ولا جرعات دواء؛ معلومات عامة وتحويل للطوارئ.
- **لا قرارات قانونية/مالية/سلامة** تتطلب مختصًا.
- **لا كتابة إبداعية طويلة** أو تلخيص/ترجمة حرة بجودة نموذج كبير.
- **لا بحث ويب** أو معلومات لحظية (طقس/أسعار) في الوضع الحالي.
- **لا استدلال مفتوح متعدد الخطوات** بلا أدوات (المرحلة 8 لم تُنفَّذ).
- **لا تشغيل كود** من المستخدم (D3 معلّق).
- **لا استخدام في أنظمة حرجة** (طيران/طبي/عسكري/مركبات) بلا مراجعة.
- **لا تعميم** على لغات/لهجات/أجهزة لم تُختبر.

## المكوّنات والبيانات

| المكوّن | الوصف | بيانات/مصدر |
|---|---|---|
| التطبيع العربي | توحيد الحروف/الأرقام/اللهجات | قواعد داخلية |
| المصنّف/الراوتر | نية + أداة + بوابة ثقة | قواعد + corpus صغير |
| الاسترجاع | BM25+ / 3-gram / TF-IDF | 181 وحدة |
| الأدوات | حساب/وحدات/وقت/هجري/بيانات Opt-in | كود داخلي |
| الحوار | حالة قصيرة، إحالات، حد توضيح | ذاكرة جلسة |
| المحتوى | 11 حزمة | كتابة آلية + مصادر مفتوحة/مراجع |
| التخزين | SharedPreferences + AES-GCM | محلي |

لا يوجد تدريب على بيانات المستخدم. لا تُرسل المحادثات إلى خادم. لا تُستخدم
مخرجات المستخدم لتدريب أي نموذج.

## القياس

**لم يُشغَّل أي قياس.** لا دقة، لا p95، لا Wilson، لا McNemar، لا مقارنة عمياء.
البروتوكول جاهز في [EVALUATION-PROTOCOL.md](EVALUATION-PROTOCOL.md)، والنتائج
المعلنة في [RESULTS.md](RESULTS.md) هي «لا توجد نتائج».

### المقاييس المعرّفة (بانتظار تشغيل)

- دقة الإجابة على 223 حالة + 50 held-out (مع Wilson 95%).
- دقة النية/التوجيه.
- الامتناع الصحيح (refusal) عند الجهل.
- زمن الرد (median/p95) على جهاز.
- بدء التطبيق وjank (Macrobenchmark).
- ثبات/اتفاق المحكّمين في المقارنة العمياء.

### ما لا يثبته أي مقياس

- «الذكاء العام» أو التفوق على نموذج سحابي.
- صحة المحتوى في كل المجالات (خصوصًا الدين/الصحة).
- الأمان أو الخصوصية (لها وثائق منفصلة).

## القيود

- 181 وحدة فقط؛ تغطية غير متوازنة، وفئات ضعيفة (برمجة/صحة/دراسة).
- محتوى مولّد آليًا بلا مراجعة بشرية (D31)، وبعض التراخيص غير محسومة.
- فهم لهجي/نحوي محدود، وأخطاء إملائية/فرانكو غير مغطاة كاملًا.
- لا نموذج توليدي، ولا شبكة، ولا embeddings، ولا تنفيذ كود.
- OCR غير عامل بلا tessdata؛ ML Kit يعتمد على خدمات جوجل.
- بعض البيانات غير مشفرة؛ لا تدقيق أمني؛ لا اختبار جهاز.
- لا APK منشور؛ لا توقيع/إعادة إنتاج متحققين.
- لا اختبار وصول/TalkBack/RTL.
- لا مراجعة مستقلة للاختبارات أو الخطة.

القائمة الكاملة: [LIMITATIONS.md](LIMITATIONS.md).

## الاعتبارات

### السلامة

- لا فتوى ولا تشخيص. الحالات الحرجة تُحال لمختص/طوارئ.
- أزمة إيذاء النفس: رد محلي محدود + إحالة، وليس بديلًا عن مساعدة طارئة.
- لا تعليمات خطرة (أسلحة/اختراق/ضرر) ضمن نطاق المنتج.

### الخصوصية

- لا شبكة ولا حساب.
- تشفير جزئي كما هو موضح؛ لا ادعاء حماية كاملة.
- الاحتفاظ محلي حتى الحذف؛ راجع [PRIVACY.md](PRIVACY.md).

### العدالة والشمول

- اللهجة المصرية/الفصحى أولوية، وقد تضعف جودة الردود لغيرها.
- لا قياس أداء لمجموعات لهجية/عمرية/إعاقة.
- المحتوى الديني قد لا يمثل كل المذاهب/الآراء؛ يحيل ولا يحسم.

### الشفافية

- كل قيد معروف مصدره `release/limitations.json` ويُعرض داخل التطبيق.
- لا نتائج مختلقة؛ لا ادعاء نجاح بلا تشغيل.
- سجل القرارات في [DECISIONS.md](../plans/DECISIONS.md).

### الاستدامة

- حجم الحزم والفهرس صغير نسبيًا، لكن حجم APK والتبعيات (Firebase/ML Kit/
  Tesseract) لم يُقَس. Firebase غير مستخدمة ومرشحة للإزالة (D7).

## التوصيات

1. لا تنشر اسمًا/رقمًا قبل تشغيل المجموعة ونشر الفواصل.
2. استخدم [RELEASE-CHECKLIST.md](RELEASE-CHECKLIST.md) قبل أي إصدار.
3. راجع القيود قبل الاستخدام في سياق حساس.
4. أبلغ عن الأخطاء بلا بيانات شخصية؛ وثّق الإصدار/commit.
5. لا تعتبر التشخيص داخل التطبيق بديلًا عن قياس شامل.
