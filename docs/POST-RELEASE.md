## عمل هندسي مطلوب (بأولوية)

### P0 — قبل أي إصدار عام

1. **تشغيل حقيقي:** `./gradlew :app:testDebugUnitTest` + هارنس 223×8 + held-out،
   وحفظ `results.json`/الهاش في سجل جديد. حدّث `release_manifest.json` من
   `not-run` إلى `measured` وسجّل الأمر/التاريخ/commit.
2. **بناء APK debug وrelease** على جهاز/CI، تثبيت، ثم `apksigner verify` ونشر
   الهاش/البصمة. أي فشل يُصلح قبل النشر.
3. **قياس أداء أولي** على API 24/31/34/36 (Macrobenchmark + Perfetto + حجم APK).
4. **قرار قناة التوزيع** (GitHub Releases/F-Droid/Play/مباشر) وسياسة ترقيات.
5. **تقليل ادعاءات الواجهة** المتبقية بعد تدقيق المرحلة 6 (تم إصلاح الحرج منها).

### P1 — سلامة وخصوصية

6. **تشفير المهام/المواعيد/المزاج/الشخصية** أو توثيق قرار عدم التشفير نهائيًا.
7. **اختبار النسخ الاحتياطي/N2N** على Android 12+ (bmgr + جهازين)، وتحديث
   [PRIVACY.md](PRIVACY.md) بالنتيجة الفعلية.
8. **إزالة Firebase/Gemini/Google services غير المستخدمة** أو تصحيح
   `metadata.json` وإزالة `MAJOR_CAPABILITY_SERVER_SIDE_GEMINI_API`.
9. ~~تثبيت إجراءات CI بـSHA + `persist-credentials: false`~~ ✅ نُفّذ بنيويًا في 2026-10-29؛ يبقى **تفعيل CI وتشغيله** وإضافة gitleaks/trufflehog كطبقة تاريخية.
10. **اختبار AndroidKeyStore/الترحيل** على API 24–36، وتوثيق `isHardwareBacked`.
11. **خطة استجابة ثغرات** (GitHub Security Advisory) دون اختراع بريد/مكافأة.

### P2 — جودة ومحتوى

12. **مراجعة بشرية للمحتوى** أو تثبيت تنازل D31 في كل الوثائق (الحالي: متنازل).
13. **حسم تراخيص seed-legacy** والمواد المورثّة في `license-audit.md`.
14. **تغطية محتوى البرمجة/الصحة/الدراسة** وقياس الاسترجاع، لا العدد فقط.
15. **OCR:** إضافة `ara.traineddata`/`eng.traineddata` بترخيصها وحجمها، أو
    إزالة الادعاء من الواجهة.
16. **إمكانية وصول:** TalkBack، أحجام الخطوط، التباين، RTL، اختبار Compose.

### P3 — مسار التقارب (7–9)

17. **الوضع المتقدم** الاختياري خلف `AdvancedMode`، خارج النواة، مع صفحة خصوصية
    وزر حذف الأوزان (D9/D11). لا نموذج افتراضي.
18. **الاستدلال الوكيلي** بحدود D13 (≤8 خطوات، ≤2 إعادة تخطيط، ≤4s p95) وسلامة
    إجراءات، أو النسخة الحتمية إن رُفض D9.
19. **قياس التكافؤ** وفق D14/D15 مع لقطات مؤرخة وفواصل ثقة، أو عدم نشر أرقام.
20. **بطاقة/تقرير ما بعد الإطلاق** يحدّث القيود والنتائج، لا يجمّلها.

## ما لا تفعله هذه التذكرة

- لا تفتح قناة توزيع تلقائيًا.
- لا تفترض قبول D9 أو أي قرار مالك.
- لا تسمح بنشر نتيجة بلا ملف/هاش/أمر/تاريخ.
- لا تُغلق بإنجاز جزئي؛ تُغلق بندًا بندًا بدليل.
