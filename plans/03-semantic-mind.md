## 1. الفكرة المحورية

`SemanticSearchEngine.kt` الحالي يعلن: «يبحث بالمعنى وليس الكلمات فقط»، لكن تنفيذه **TF-IDF + cosine + قاموس مرادفات ثابت** — أي أنه لا يفهم أن «ازاي أبدأ برمجة» و«عايز أتعلم كود» نفس السؤال. المنافس بنى فهرس BM25 هجينًا ورفع درجته إلى 86%، لكنه اعترف أن الاسترجاع فقط «بيختار من ردود جاهزة».

**هدف زهرة:** استرجاع هجين قابل للتفسير، مع **إثبات** أن الأسئلة المعاد صياغتها تتحسن — لا مجرد ادعاء.

```
وحدات المعرفة (packs) ──► فهرس زمن البناء (BM25 + char-3grams + stems) ──► JSON مُشحون في assets
السؤال ──► تطبيع (م 1) ──► استعلام ──┬── BM25 (كلمات)
                                     ├── بصمات حروف Jaccard (أخطاء إملائية/تشكيل)
                                     └── TF-IDF cosine (مرادفات)
                              ──► دمج مرجّح ──► أعلى 3 ──► بوابة الثقة (م 1)
```

## 2. مسارات العمل

### المسار A — مخطط «وحدة المعرفة» (عقد مشترك مع المرحلة 5)

اتفق مع وكيل المرحلة 5 على هذا المخطط قبل كتابة أي كود:

```json
{
  "id": "prog-js-closures",
  "title": "ما هو الـ Closure في JavaScript؟",
  "intent": "define_word",
  "pack": "programming",
  "q": ["يعني ايه closure", "شرح الـ closures في جافاسكربت", "what is a closure", "3ayez afham closure"],
  "a": ["...تعريف...", "...مثال كود...", "...حالة استخدام..."],
  "tags": ["javascript", "functions", "scope"],
  "source": {"name": "MDN", "url": "https://developer.mozilla.org/...", "license": "CC-BY-SA-2.5"},
  "verifiedAt": "2026-10-26",
  "safety": "none",
  "weight": 1.0
}
```

قواعد إلزامية:
- `q` ≥ 4 تنويعات لكل وحدة (مصري/فصحى/فرانكو/إنجليزي)، وإلا يفشل مدقق البناء.
- كل وحدة ليها `source` أو `authored: true` مع مسؤول واضح.
- `a` لا يحتوي على وعود زمنية/طبية/دينية بلا مصدر.

### المسار B — خط أنابيب البناء (Build-time pipeline)

1. مهمة Gradle `:app:generateKnowledgeIndex` (أو سكربت Python في `tools/build_index.py` يُستدعى من Gradle): تقرأ `packs/*/pack.json` + `assets/*_kb.json` القديمة بعد ترحيلها، وتُنتج `app/src/main/assets/knowledge_index.json`.
2. الحساب زمن البناء فقط: تجذيع، `df`/`idf`، أطوال المستندات، بصمات حروف (3-gram) لكل سؤال، ومتوسطات TF-IDF. وقت التشغيل لا يحسب غير استعلام المستخدم.
3. File size budget: الفهرس ≤ 8MB مضغوط (أو ما يتوافق مع D7) + فحص في CI يمنع تجاوزه.
4. **مدقق جودة** `KnowledgeRecordValidator.kt` (موجود مسبقًا): وسّعه ليفحص التكرار، غياب التنويعات، روابط مكسورة، وحدات بلا مصدر. failing build = بيانات ناقصة.

### المسار C — الاسترجاع الهجين (`knowledge/unit/HybridRetriever.kt`)

1. **BM25** بصيغة BM25+ (`k1=1.2`, `b=0.75`, `delta=1`) مع أوزان: أسئلة الوحدة ×3، العنوان ×2، الوسوم ×2، الإجابة ×1 — نفس فكرة المنافس لكن موثقة بالمعادلة.
2. **بصمات حروف (char 3-gram) + Jaccard**: يتحمل «ازاي/إزاي/azzay» وأخطاء الكتابة.
3. **TF-IDF cosine**: أعد استخدام `SemanticSearchEngine` كأحد الإشارات لا كالنظام كله.
4. **دمج مرجّح قابل للمعايرة**: `score = w1*bm25 + w2*charSim + w3*cosine`، الأوزان تُضبط على **مجموعة تدريب فقط**، ثم تُقاس على `held-out`. سجّل الأوزان في `evidence/phase-03/weights.json`.
5. **تطبيع الدرجات**: كل إشارة تُطبّع إلى [0,1] قبل الدمج، ثم تُمرّر لـ `ConfidenceGate` (المرحلة 1) — لا عتبات جديدة مبعثرة.
6. **إخراج قابل للتفسير**: لكل نتيجة، احفظ `matchedTerms`, `scoreBreakdown`, `unitId` — ضروري لتشخيص الفشل ولزر «تشخيص».

### المسار D — المستوى B (اختياري — لا يُدمج بلا إثبات)

1. جرّب نموذج `multilingual-e5-small` مُكمّم INT8 عبر ONNX Runtime على الجهاز (أو البديل العربي ATM-V2) — كلاهما **غير توليدي**، فلا يخالف Zero-LLM.
2. قِس على نفس `held-out`: الدقة، zمن p95 على جهاز متوسط، حجم النموذج، استهلاك الذاكرة، أثر الإقلاع البارد.
3. **قاعدة الرفض التلقائي:** أي تحسّن < 10 نقاط، أو حجم > 25MB، أو p95 > 150ms → لا يُدمج، ويُسجّل القرار في `DECISIONS.md` (D2) مع الأرقام.
4. إن دُمج: خلف feature flag `SEMANTIC_EMBEDDINGS`، مع تحميل عند أول استخدام فقط ومؤشر تقدّم، وخيار تعطيل من الإعدادات.

### المسار E — اختبار «الصياغة المختلفة»

1. أنشئ من `held-out` مجموعة `paraphrase-100`: نفس المعنى بصياغة مختلفة (مصري / فصحى / فرانكو-عرب / إنجليزي).
2. قِس قبل/بعد: `top-1 accuracy`, `top-3 recall`, `mean reciprocal rank`, زمن p50/p95.
3. **اختبار مضاد (negative control):** أسئلة متشابهة الكلمات ومختلفة المعنى («ازاي اعمل موقع» مقابل «ازاي اعمل حساب») لازم ما يرجّعش نفس الوحدة. المنافس فشل في هذا بالضبط في فئة البرمجة.
