# خطة زهرة — التنفيذ الوظيفي ثم التقارب

**تحديث السياسة: 2026-10-29 · المراحل: 0–9**

## سياسة المالك: إلغاء إلزام الإثبات نهائيًا

أُلغيت من جميع المراحل متطلبات تشغيل CI، وتقارير JUnit، وبناء أو نشر APK، وتسجيل baseline بوضع `recorded`، وتشغيل القياسات وإنتاج `results.json` وartifacts، ومعايير القبول الرقمية وبوابات الانتقال المرتبطة بها. ليست هذه المتطلبات مؤجلة إلى بيئة أخرى، ولا يمنع غيابها بدء مرحلة أو اكتمال تنفيذها. القرار: [D20](DECISIONS.md).

اكتمال التنفيذ **لا يعني** نجاح اختبارات أو ثبوت دقة أو أداء. لا يُنشر ادعاء نجاح بلا تشغيل فعلي، ولا تُختلق أرقام أو روابط. أدوات القياس والاختبارات الموجودة باقية دون تعديل؛ تشغيلها اختياري ولا تُعد نتائجها شرط إكمال في الخطة.

## القواعد المستمرة

1. البحث قبل التنفيذ R0 وفق [PRE-FLIGHT.md](PRE-FLIGHT.md)، دون اشتراط CI لقبوله.
2. لا اختلاق معرفة أو ذاكرة أو مصادر؛ الامتناع الصريح عند الجهل.
3. النواة 0–6: Zero-LLM وZero-Network افتراضيًا. أي شبكة تتطلب موافقة صريحة.
4. لا حسم لقرارات المالك المعلقة، خصوصًا D1 وD2 وD3.
5. لا حذف اختبار أو إضعاف توقعاته لإخفاء الفشل. لا تعديل لمجموعة القياس المجمدة بسبب النتائج.
6. إضافة اختبارات للسلوك الجديد لا تعني وجوب تشغيلها أو إنتاج JUnit لإكمال التنفيذ.
7. توثيق القيود وما لم يُشغّل بوضوح، وعدم تحويل حالة مرحلة إلى نجاح مقاس بمجرد تعديل الخطة.

## الحالة

لم تُعَد مراجعة اكتمال التنفيذ بهذا التعديل. سجلات المرحلة 0 في [evidence/phase-00](../evidence/phase-00/README.md) تاريخية وليست شروطًا نافذة على المراحل التالية. المراحل 1–9 لم يُنفّذ منها شيء في تعديل السياسة هذا.

**تحديث 2026-10-29:** المرحلة 3 (الفهم الدلالي) نُفّذت وظيفيًا — سجلها في
[evidence/phase-03](../evidence/phase-03/README.md) مع القيود المعلنة وغياب تشغيل Gradle/CI (D20).
المرحلة 4 نُفّذت وظيفيًا بما فيها توحيد مستهلكات السياق وحل الإحالات وحد التوضيح والتحقق النهائي
وعرض الذاكرة المعطوبة (D29، D30)؛ يبقى غير منفَّذ التحقق الفعلي على Android/جهاز وقياس الدقة. التفاصيل في
[سجل المرحلة](../evidence/phase-04/README.md). المرحلة 5 نُفّذت وظيفيًا في 2026-10-29 وفق D31: 181 وحدة في 11 حزمة، وفهرس محتوى ومدقق وتقرير تراخيص؛ المراجعة البشرية متنازل عنها بأمر المالك، والمحتوى معلّم بأنه مولّد آليًا وغير مدقق واقعيًا. تبقى تراخيص بعض المواد الموروثة غير محسومة. لم يُشغّل Gradle/CI/APK أو قياس أداء. التفاصيل: [evidence/phase-05](../evidence/phase-05/README.md). المراحل 6–9 لم تبدأ.

## طريقة العمل

اقرأ ملف المرحلة كاملًا وسجل القرارات، نفّذ البحث ثم المخرجات الوظيفية، وأضف اختبارات للسلوك الجديد ووثّق القيود. يمكن وصف العمل بأنه «مكتمل التنفيذ، غير مختبر» دون ادعاء نتائج. لا يلزم مجلد مخرجات تشغيل أو رابط workflow للإكمال.
