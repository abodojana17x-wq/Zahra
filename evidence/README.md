# دليل السجلات والأدلة

وفق [D20](../plans/DECISIONS.md)، لا يُشترط مجلد أدلة تشغيل أو CI أو JUnit أو APK أو baseline أو قياسات لإكمال أي مرحلة أو الانتقال منها. أُلغيت هذه المتطلبات نهائيًا بطلب المالك.

تبقى ملفات البحث `research.md` مطلوبة وفق R0 في [PRE-FLIGHT.md](../plans/PRE-FLIGHT.md)، دون بوابة CI.

## عند حفظ سجل اختياري

- احفظ المخرجات الفعلية كما هي، بما فيها الفشل، ولا تختلق نتائج.
- انسب الأرقام المنشورة إلى أمر التشغيل وتاريخه وإصدار الكود والمجموعة.
- لا تضف ملفات كبيرة أو APK إلى Git؛ استخدم تخزينًا خارجيًا مناسبًا عند الحاجة.
- لا تسمِّ العمل نجاحًا مقاسًا إذا لم يُشغّل.

سجلات المراحل: [`phase-00/`](phase-00/README.md) (تاريخي) · [`phase-01/`](phase-01/README.md) · [`phase-02/`](phase-02/README.md) · [`phase-03/`](phase-03/README.md) · [`phase-04/`](phase-04/README.md) · [`phase-05/`](phase-05/README.md) · [`phase-06/`](phase-06/README.md).

سجل `phase-06/` يوثّق مخرجات الإطلاق والتقييم الأعمى، ويضم جدول «ما تحقق فعليًا» مقابل «ما لم يُشغَّل»؛ لا يحتوي أي نتيجة دقة أو أداء لأنها لم تُقَس.

ملفات `phase-00/` محفوظة كسجل تاريخي؛ تعليماتها القديمة عن إلزام الإثبات لا تسري بعد D20. لم تُعدّل نتائجها أو يُدّعَ استكمال ما لم يُنفّذ.
